# MAP_PROMPT — 실행 PC에서 사내 AI와 함께 "메뉴 지도"(실제 데이터) 만들기

> 이 파일은 실행 PC(사내망)에서 쓴다. **실제 데이터는 실행 PC 밖으로 나가지 않는다.**
> 사내 AI 채팅 화면(또는 사내 AI를 연결한 AnythingLLM 채팅)에 아래 "붙여 넣을 프롬프트"를 넣고, 엑셀과 번갈아 가며 만든다.
> 파일을 AI에 올리지 않아도 된다(벡터 DB·임베딩 필요 없음). **글을 대화창에 붙여 넣고, AI가 준 CSV 줄을 엑셀에 붙여 넣는 방식**이다.
> 열의 뜻은 `docs/DATA_SCHEMA.md`.

## 지킬 원칙 (12가지)
1. **회사 데이터는 실행 PC 밖으로 나가지 않는다.** 사외 AI(Claude·ChatGPT 등), 개인 메일, 휴대폰 사진으로 옮기지 않는다. 쓸 수 있는 AI는 **사내 AI뿐**이다.
2. **사람 이름은 넣지 않는다.** 담당은 부서 이름 + 부서 대표 번호까지. (사람은 바뀌고, 개인정보는 남기지 않는다)
3. **메뉴 ID는 사람이 직접 확인한다.** 포털에서 메뉴를 열고 주소 끝의 번호를 옮겨 적는다. AI가 짐작한 ID는 쓰지 않는다.
4. **AI가 만든 줄은 원본과 한 번 대조한다.** 특히 메뉴 이름, 경로, 담당 부서. AI는 정리를 돕는 조수이지 정답 출처가 아니다.
5. **지도의 주인은 한 사람.** 시범 기간에는 본인. 줄을 고칠 때마다 `last_checked`에 오늘 날짜(예: 2026-11-25). 오래된 지도는 없는 지도보다 나쁘다.
6. **인턴도 쓴다.** 지도에는 **신입·인턴 누구나 열 수 있는 메뉴**를 넣는다. 일부만 열 수 있는 메뉴는 넣지 않거나, `description` 끝에 "(정규직만)"처럼 적는다. 권한이 따로 필요한 메뉴는 넣지 않는다.
7. **기밀은 넣지 않는다.** 영업·사업 기밀 게시판, 보안 등급이 있는 문서·메뉴는 지도에서 뺀다. 전 직원 공개 메뉴만.
8. **동의어는 실제로 들은 말로.** 두 글자 이상. 한 말이 여러 메뉴를 가리키면(예: "신청") 넣지 않는다.
9. **정답셋(eval)은 지어낸 질문 말고 들은 질문으로.** 질문 속 사람 이름·사번은 지운다.
10. **상황 대시보드는 신입·인턴이 사내 PC로 할 수 있는 일만.** 입사 전 할 일(서류, 첫날 출근 방법)과 관리자 할 일은 넣지 않는다.
11. **작게 시작해서 늘린다.** 상황 7개 → 그 카드에 걸린 메뉴 → 자주 쓰는 메뉴 20개 → 동의어 15개 → 정답셋 23개. 파일 하나를 채울 때마다 `py check_data.py`.
12. **엑셀 저장은 항상 "CSV UTF-8(쉼표로 분리)".** 열 이름(첫 줄)은 바꾸지 않는다. 숫자 ID가 날짜·숫자 모양으로 바뀌면 검사기가 알려 준다.

## 순서 (한 번에 한 파일)
| 순서 | 파일 | 원본 | 사내 AI에게 시킬 것 |
|---|---|---|---|
| 1 | `situations.csv` | 포털의 상황별 대시보드 7개 카드 글 | 카드 글을 붙여 넣고 → 상황 단계 줄로 바꾸기 |
| 2 | `menus.csv` | 포털 왼쪽 메뉴 트리, 각 메뉴 화면 | 메뉴 이름·경로를 붙여 넣고 → 메뉴 줄로(ID는 사람이 채움), 동의어 후보 제안 |
| 3 | `synonyms.csv` | 동료에게 들은 줄임말·별칭 | 들은 말 목록을 붙여 넣고 → word,standard 줄로 |
| 4 | `eval_questions.csv` | 실제로 들은 질문 | 질문을 붙여 넣고 → 일상어/메뉴이름/범위밖으로 나누기(정답 ID는 사람이 확인) |

## 붙여 넣을 프롬프트 (사내 AI 채팅 첫 메시지로)

```
너는 사내 포털 "메뉴 지도"를 만드는 데이터 정리 조수야. 나는 엑셀로 CSV 파일 4개를 채우고 있어.
내가 포털 화면의 글(메뉴 이름, 경로, 대시보드 카드 글, 들은 질문)을 붙여 넣으면, 아래 형식의 CSV 줄로 바꿔 줘.

[출력 규칙]
- 코드 블록 안에 CSV 줄만 준다. 첫 줄은 열 이름. 쉼표가 들어간 칸은 큰따옴표로 감싼다.
- 여러 값은 | 로 나눈다(예: 법카|법인카드 신청). 키워드·동의어는 두 글자 이상.
- 내가 준 글에 없는 정보는 지어내지 않는다. 모르면 칸을 비우고, 표 아래에 "확인 필요: ○○" 목록으로 알려 준다.
- 메뉴 ID(menu_id)는 절대 짐작하지 않는다. 내가 주지 않았으면 비워 둔다.
- 사람 이름·사번·개인 연락처는 넣지 않는다. 담당은 부서 이름과 부서 대표 번호만.
- 정규직만 쓸 수 있는 메뉴로 보이면 description 끝에 "(정규직만)"을 붙이고 "확인 필요"에 적는다.
- 영업·사업 기밀이나 보안 등급 문서로 보이는 것은 줄로 만들지 말고 "제외 권장"으로 알려 준다.

[파일 형식]
1) situations.csv
situation_id,situation_name,trigger_words,step_no,step_title,menu_id,site,owner_dept,tip
- 상황 7개: S01 신규 입사 / S02 손님 방문 / S03 출장 / S04 근무지 이동 / S05 기숙사 / S06 식사 / S07 재충전
- trigger_words: 그 상황을 말할 때 직원들이 쓸 법한 말 3~6개(예: 손님|방문|외부인|미팅 손님)
- 같은 상황의 줄은 trigger_words를 똑같이 쓴다. step_no는 1부터. site는 사업장별로 다르면 사업장 이름, 같으면 "전체".

2) menus.csv
menu_id,menu_name,path,synonyms,description,owner_dept,contact,last_checked
- path는 "큰 메뉴 > 중간 메뉴 > 메뉴" 모양. description은 한 문장. last_checked는 YYYY-MM-DD.
- synonyms에는 직원들이 실제로 쓸 법한 말을 3~6개 제안한다(줄임말, 상황 말, 일상어). 메뉴 이름을 그대로 반복하지 않는다.

3) synonyms.csv
word,standard,note
- word = 사람들이 쓰는 말, standard = 메뉴 지도에 있는 말, note = 줄임말/옛 표현 등.

4) eval_questions.csv
q_id,q_type,question,answer_ids,note
- q_type: 일상어(메뉴 이름이 안 들어간 질문) / 메뉴이름(메뉴 이름으로 묻는 질문) / 범위밖(지도에 답이 없는 질문 → answer_ids는 UNKNOWN)
- q_id: 일상어 E01~, 메뉴이름 N01~, 범위밖 X01~
- answer_ids는 내가 알려 준 menu_id만 쓴다. 모르면 비워 두고 "확인 필요"에 적는다.

이해했으면 "준비됐어요. 어떤 파일부터 할까요?"라고만 답해 줘.
```

## 이어서 쓰는 짧은 지시 예시
- `1번 situations.csv야. 아래는 "손님 방문" 상황 카드 글이야. 줄로 바꿔 줘.` + 카드 글 붙여 넣기
- `2번 menus.csv야. 아래 메뉴 이름과 경로로 줄을 만들고, 동의어 후보도 제안해 줘. ID는 내가 채울게.` + 목록 붙여 넣기
- `아래 질문들을 eval_questions.csv 줄로 나눠 줘. 정답 ID는 이 목록에서만 골라: (ID 목록)`
- `방금 만든 menus 줄에서 동의어가 두 메뉴 이상에 겹치는 말을 찾아 줘.`

## 다 채운 뒤 (실행 PC 명령 창)
```
py check_data.py
py eval.py
py -m guide.llm "연차 쓰려면 어디로 가?"
```
- `check_data`가 "문제 없음"이 될 때까지 고친다.
- `eval`의 일상어 줄에서 길잡이가 틀린 질문 → 그 질문의 말을 `synonyms.csv`나 메뉴 `synonyms`에 더한다(규칙으로 찾게 만들기). AI는 규칙이 못 찾을 때만 돕는다.
